## Что сделано

### Исследование и официальные контракты

- Прочитан актуальный публичный каталог API Госуслуг на 12.08.2026.
- Зафиксирован manifest 28 документов: URL, дата, размер и SHA-256; выделены
  21 спецификация услуги и 134 XML/XSD-блока.
- Официальные DOCX/PDF и дословно извлечённые XML/XSD исключены из Git и
  package/runtime-артефактов: явная лицензия на их перераспространение не найдена.
  Их можно скачать и проверить локально через `scripts/sync_api_for_gu_docs.py`.
- Сравнён `ofstudio/go-api-epgu` v1.0.1 со спецификацией v1.14. Точного
  стороннего Python-аналога gusmev lifecycle не найдено; существующий
  `gosuslugi-api` относится к ГИС ЖКХ и не является аналогом.

### Python-библиотека

- Локальный `python-epgu` доведён до версии `0.2.0`: типизированные модели,
  v1.14 endpoints, статусы/словари/файлы, безопасные OAuth state/callback,
  ext-app token provider, ZIP/CAdES abstraction, XML validation.
- Исправлены `order.id`, вложенный статус, пустой cancel response, точный
  download contract, zero-based pagination, chunk `.z001`, HTTP 206/200,
  5-50 MB части и общий 5-минутный deadline.
- Добавлен типизированный Госключ для трёх проверяемых контрактов и fail-closed
  reference-вариантов, а также единый `submit_goskey(...)`, выбирающий прямой
  `push` или `order + push/chunked`.
- Секреты удалены из `repr`/`str` и сообщений ошибок; JWT `exp` используется
  только для fail-safe TTL; `CryptoProSigner` требует явный thumbprint.
- Последний полный SDK checkpoint: **182 passed**, branch coverage **93,97%**,
  Ruff format/check и mypy - успешно. Wheel/sdist ранее успешно прошли build и
  `twine check`; после самых последних правок сборку нужно повторить.

### Каталог услуг, backend и frontend

- Создан versioned backend registry на 21 услугу. Доступны только три
  проверенных профиля Госключа: `10000000374/УНЭП`, `60025907`, `60080470`.
  Остальные 18 видимы как reference и заблокированы fail-closed; `60010153`
  отключён из-за демонстрационных персональных данных и отсутствия типизированной
  формы.
- Backend использует разные transport/archive contracts, реальный chunking,
  per-service validation, Госключ SDK, CSRF origin guard, явный сертификат,
  ограничение загрузок, streaming download и sanitized errors.
- Последний стабильный backend checkpoint до незавершённого concurrency-pass:
  **77 passed, 5 skipped**, Ruff успешно, внутри Docker.
- Frontend умеет выбирать все 21 профиля, показывает состояние/версию/источник,
  блокирует reference-профили, имеет отдельную форму Госключа, runtime ОКАТО,
  adaptive transport и защиту от устаревших async-ответов.
- Убрано автоматическое долговременное хранение тел документов; добавлены
  очистка локальных данных, безопасные download/logging helpers, CSP и security
  headers. Предыдущий стабильный frontend checkpoint был зелёным, но после
  заключительных правок полный suite не запускался.
