## Как пользоваться гайдом

В интерфейсе откройте «Гайд» без входа. Нажатие на блок показывает текст,
проверки, источники и переходы. Для переходного периода выберите маршрут
«Переход от старого процесса к новому», для входа на сайт маршрут «ЕСИА». Даты каждого
источника видны отдельно от даты редакторского среза.

Тот же набор доступен через `GET /v1/knowledge/routes`,
`GET /v1/knowledge/routes/{route_id}/nodes/{node_id}` и MCP
`knowledge_get_node`. Справочные инструменты не выдают доступ и не исполняют
шаги схемы. Изменение текста не включает новую capability.

## Что проверять при обновлении документов

1. Сверить официальный источник, его редакцию и конкретный раздел.
2. Изменить только относящиеся к нему шаги и индивидуальную дату источника.
3. Сохранить разные роли: пользователь входа, заявитель ФЛ/ЮЛ/ИП, представитель,
   владелец ИС и получатель подписи.
4. Синхронизировать UI-копию через `knowledge/tools/sync_ui_copy.mjs`.
5. Проверить схему, доступность узлов графа, HTTP/MCP и отображение интерфейса.

Проверка кода по новому контракту оформляется отдельно: запросы и подпись,
транспорт, позитивные и отрицательные ответы, отсутствие повторной подачи,
результат авторизованного TEST-прогона. Номер версии в конфигурации нельзя
повышать только на основании появления новой документации.
