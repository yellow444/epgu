# personal/ - личные сертификаты

Локальный каталог для сертификатов пользователей/организаций (`.cer`, `.crt`,
`.pfx`, `.p12`). Всё содержимое, кроме этого README и `.gitkeep`, игнорируется
Git.

Файл сертификата не содержит закрытый ключ сам по себе. Для подписи установите
сертификат и связанный ключевой контейнер в хранилище CryptoPro того пользователя
ОС, от имени которого запускается backend. Ограничьте права каталога и не
копируйте личные сертификаты, PIN и ключевые контейнеры в репозиторий.
