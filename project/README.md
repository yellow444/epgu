# Рабочий каталог проекта

Основное описание, бейджи и быстрый старт находятся в [корневом README](../readme.md).

- [Backend](./api-gosuslugi-backend/README.md)
- [Frontend](./api-gosuslugi-client/README.md)
- [Python SDK](./python-epgu/README.md)
- [Документация](./docs/README.md)
- [Инструменты](./scripts/)

Команды с путями `scripts/`, `docs/` и `api-gosuslugi-*` выполняйте из этого каталога. Относительное расположение компонентов сохранено; лицензия и служебные Git-файлы остаются в корне репозитория.

Существующие установки автоматически не переносятся. При подключении приватных дополнений к новой копии указывайте `project/` как целевой каталог компонентов, а не корень Git. Уже работающий стенд этим изменением не обновляется.
