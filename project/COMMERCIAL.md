## Что доступно без покупки коммерческой лицензии

Python SDK epgu-api с версии 0.4.0, epgu-knowledge и epgu-mcp с версии 0.2.0 распространяются по Apache 2.0. Их можно встраивать в закрытые программы при соблюдении условий лицензии. Отдельная платная лицензия для такого использования не требуется.

Backend и веб-интерфейс EPGU остаются под AGPL-3.0-or-later. Коммерческое использование разрешено на ее условиях. Требования к исходникам определяются лицензией и способом использования; сама по себе AGPL не запрещает SaaS. [Карта компонентов](LICENSING.md).

## С чего начать

| Кому | Бесплатный старт | Что можно заказать отдельно |
| --- | --- | --- |
| Небольшой компании с одной организацией | Гайд, карточка подключения, публичный mock-цикл; Bell Free для чтения уведомлений по отдельным условиям | Настройку одного сценария, импорт в учетную систему, обучение оператора |
| Разработчику 1С, CRM или ERP | Apache SDK, knowledge и MCP для своего приложения, в том числе закрытого | Адаптер, проверку интеграции и сопровождение |
| Крупной компании или интегратору | Проверку API, контрактов и воспроизводимого mock-цикла до закупки | Поставку выбранных модулей, несколько организаций, внедрение и согласованные условия поддержки |

Для одного подключения нет обязательной покупки многоконторной версии. Бесплатный код не означает готовый доступ к услугам: учетную запись, сертификаты и разрешения оператора оформляют отдельно.

Пилот можно ограничить одной организацией и одной услугой. В предложении фиксируем результат: какие данные получаем, какие действия разрешены, как исключаем повторную подачу и чем подтверждаем приемку. Роли, масштабирование, размещение и SLA для крупного заказчика обсуждаются по требованиям; наличие их всех в готовом продукте этот документ не обещает.

## Что не входит автоматически

Доступ к Госуслугам выдает оператор. Права на КриптоПро CSP, pycades и другие сторонние продукты приобретаются у их поставщиков. Каталог из 21 профиля не означает 21 принятый живой сценарий: в поставке перечисляются конкретные проверенные услуги и среды.

Отдельная папка с модулем не отменяет условия AGPL для производной работы. Дополнительные права предоставляются только в отношении кода, на который у предоставляющего их лица есть соответствующие права. Сторонние лицензии сохраняются.

## Bell

[EPGU Bell](https://github.com/yellow444/epgu-bell) распространяется отдельно. Bell Free является бесплатной закрытой сборкой для одной организации на установку; Multi и работы по внедрению обсуждаются отдельно. Переход лицензий пакетов EPGU не меняет лицензию приложения Bell.

Ранее выпущенные версии всех продуктов продолжают использоваться на условиях, с которыми они были получены.
