# Обзорные заметки по системе

Краткие конспекты по проекту: что это, как устроено, как запускать, какие есть
подводные камни и что уже решено по ходу работы. Дополняют основную документацию
в каталоге `docs/`.

- `01-overview.md` - назначение системы и тестовые контуры.
- `02-architecture-and-run.md` - сервисы, порты, тома, команды запуска.
- `03-config-and-known-issues.md` - переменные окружения и частые ошибки.
- `04-api-reference.md` - эндпоинты бэкенда и структура фронтенда.
- `05-journal.md` - журнал работ по датам: что делали и чем закончилось.
- `06-repo-and-identity.md` - репозиторий, ветки, авторство, правила по текстам.
- `07-licensing-and-publication.md` - AGPL плюс коммерческая лицензия, PyPI.
- `08-access-and-certificates.md` - доступ в тестовый контур и сертификаты.
- `09-open-items.md` - открытые вопросы и риски.

Порядок чтения при возвращении к проекту: `01`, `03`, затем `09` и последняя
запись в `05`.
