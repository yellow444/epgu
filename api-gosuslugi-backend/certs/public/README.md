# public/ - публичные CA

Здесь хранятся только публичные сертификаты, используемые как справочный набор.

| Файл | Назначение |
|---|---|
| `rootca.cer` | Корневой УЦ Минцифры |
| `ca-root.crt` | Дополнительный корневой УЦ |
| `test_ca_rtk2.cer` | Тестовый УЦ ЕСИА (RTK2) |
| `cacerts.p7b` | Пакет промежуточных CA |
| `der.cer` | Промежуточный CA |
| `2F0CB09BE3550EF17EC4F29C90ABD18BFCAAD63A.cer` | Промежуточный CA |

Оператор должен проверить актуальность цепочки для выбранного контура и
установить необходимые корни в системное/CryptoPro-хранилище с правами
администратора. Не доверяйте сертификату только потому, что он лежит в этом
каталоге.

Личные сертификаты и закрытые ключи находятся вне Git; см.
[../personal/](../personal/README.md).
