## Что сохранять при распространении Apache-компонентов

Для SDK, knowledge и MCP действуют условия Apache 2.0. Вместе с распространяемой копией передавайте LICENSE, сохраняйте применимые авторские уведомления и содержимое NOTICE. Измененные файлы должны содержать уведомление об изменениях. Точный объем требований определяет раздел 4 лицензии.

Уведомления можно включить в читаемый файл NOTICE, документацию или подходящий раздел уведомлений приложения в соответствии с лицензией. Для готового продукта удобно использовать раздел «О программе» или THIRD_PARTY_NOTICES. Ссылка только на этот репозиторий не заменяет копию лицензии и нужные уведомления.

В каждом из трех пакетов уже лежат LICENSE и NOTICE. Сохраняйте их при перепаковке wheel, контейнера или поставки для заказчика. Если в поставку входят несколько компонентов, сохраните применимые уведомления каждого из них, включая сторонние атрибуции.

Пример записи в перечне компонентов:

```text
EPGU: epgu-api / epgu-knowledge / epgu-mcp
Project created by Maksim Sitnikov (yellow444).
https://github.com/yellow444/epgu
Apache License, Version 2.0.
See the accompanying component LICENSE and NOTICE files.
```

Этот пример дополняет поставку, но не заменяет полное содержимое применимых NOTICE. Уведомление об авторстве не означает, что автор одобрил ваш продукт или предоставляет ему поддержку.

## Как поддержать проект

Если пишете об интеграции, будем рады ссылке на EPGU и упоминанию автора. Можно поставить звезду на GitHub, прислать исправление или заказать внедрение. Это добровольные способы поддержки, а не дополнительные условия Apache.

Обязательной рекламной плашки, ссылки на каждом экране или покупки лицензии для встраивания этих пакетов нет. Apache не передает права на товарные знаки и не разрешает выдавать чужую разработку за свою.

## Остальные компоненты

Публичная копия backend и UI остается под AGPL-3.0-or-later. Для собственных частей есть коммерческая альтернатива по отдельному соглашению. Условия уведомлений и исходников определяются выбранной лицензией; сторонние уведомления сохраняются при любом варианте. Bell распространяется отдельно и не становится открытым приложением вслед за Apache-пакетами. Полная [карта лицензий](LICENSING.md) и [коммерческие предложения](COMMERCIAL.md).
