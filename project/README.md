Команды с путями `scripts/`, `docs/` и `api-gosuslugi-*` выполняйте из этого каталога. Относительное расположение компонентов сохранено; служебные Git-файлы остаются в корне репозитория. [Карта лицензий компонентов](LICENSING.md): SDK, knowledge и MCP под Apache-2.0, backend и UI под публичной AGPL-3.0-or-later или отдельным коммерческим соглашением на собственные части. [Коммерческое сопровождение](COMMERCIAL.md).

Существующие установки автоматически не переносятся. При подключении приватных дополнений к новой копии указывайте `project/` как целевой каталог компонентов, а не корень Git. Уже работающий стенд этим изменением не обновляется.
