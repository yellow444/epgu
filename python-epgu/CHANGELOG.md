# Changelog

Все значимые изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
проект следует [семантическому версионированию](https://semver.org/lang/ru/).

## [0.2.0] - 2026-08-12

### Добавлено

- Модели `OrdersPage`, `DictionaryResult` и `DictionaryItem`, сохраняющие
  `count`, `totalCount`, `orderSearchStatus` и данные вложенного статуса.
- Безопасный `AasClient.exchange_callback`: проверка redirect URI, OAuth-ошибок,
  одноразового `state`, срока его жизни и защита от повторного callback.
- Функция `validate_xml` с отключёнными DTD, внешними сущностями и сетью.
- Матрица CI для Python 3.10-3.14, `ruff`/`mypy`, coverage gate, сборка
  wheel/sdist, `twine check`, `pip-audit` и выпуск через PyPI Trusted Publishing.
- Типизированный слой Госключа для услуг `10000000374`, `60025907`, `60079416`
  и `60080470`: capability-реестр, XSD-ориентированная генерация XML,
  обязательные отделённые подписи всех файлов и адаптивный транспорт.
- Явная проверка окна подписания Госключа: срок в будущем, московский часовой
  пояс и не более 24 часов в момент отправки.
- Высокоуровневый `submit_goskey`, который валидирует capability и срок,
  подписывает комплект и выбирает прямой `push` либо `order + push/chunked`.

### Изменено

- Контракты клиента синхронизированы со спецификацией API ЕПГУ v1.14:
  `order.id`, `content[].status`, embedded-ошибки НСИ и скачивание через
  `currentStatusHistoryId` + `terrabyte://`.
- `push_chunked` автоматически делит архив, использует поля `chunk=0..n-1` и
  имена `.z001`, `.z002`; ответ каждого чанка обязан содержать тот же `orderId`.
- `order_info` и `cancel_order` поддерживают вызов без устаревшего JSON-тела;
  пустой HTTP 200 ответа отмены считается успехом, HTTP 204 - ошибкой поиска.
- Одношаговый `submit_application(..., chunked=False)` больше не создаёт лишний
  черновик перед `/push`.
- Диапазоны зависимостей ограничены следующей major-версией. Wheel/sdist
  включают исходники, примеры и лицензионные файлы, но не копии официальных
  XSD-тестовых фикстур, права на распространение которых отдельно не заявлены.

### Исправлено

- Исправлено имя первой части: `piev_epgu.z001` вместо
  `piev_epgu.zip.z001`.
- Устранена потеря реального ID заявления из поля `id` и информации о
  ненайденных заявлениях (`orderSearchStatus=NOT_FOUND`).
- Исправлен разбор вложенной JSON-ошибки API и строкового `expires_in` ЕСИА.
- ZIP-конструктор отклоняет traversal-пути, абсолютные и повторяющиеся имена.
- Противоречивые варианты Госключа (`10000000374/УКЭП`, `60079416`) завершаются
  fail-closed с описанием расхождения официального документа и XSD.

## [0.1.0] - 2026-06-28

### Добавлено
- Клиент `EpguClient` для API gusmev/nsi: `create_order`, `order_info`,
  `cancel_order`, `push`, `push_chunked`, `orders_status`, `updated_after`,
  `dictionary`, `download_file`.
- Аутентификация: `OrgTokenProvider` (ext-app по API-Key + ГОСТ-подпись) и
  `AasClient` (OAuth2 ЕСИА для граждан).
- Слой подписи за интерфейсом `Signer`: `CryptoProSigner` (КриптоПро/pycades) и
  `CallableSigner` (внешний механизм).
- `OrderArchive` - сборка ZIP-комплекта документов с отсоединёнными подписями.
- Сценарий «под ключ» `submit_application`.
- Преднастроенные контуры `TEST` / `PROD`, типизированные модели, тесты, примеры.
- Маркер типов `py.typed` (PEP 561).
